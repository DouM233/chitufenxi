# Coze 工作流设计

目标：把网页聊天界面收到的文字和文件交给 Coze，由 Coze 调用 `gpt5.6sol` 完成客服聊天需求分析，并把结果沉淀到《赤兔历史分析结果》。

## 一、Bot 名称

```text
赤兔客服聊天分析师
```

## 二、模型

```text
gpt5.6sol
```

如果 Coze 后台里的模型显示名不同，以后台可选模型为准，但项目变量统一命名为：

```text
ANALYSIS_MODEL=gpt5.6sol
```

## 三、入口参数

网页发送给 Coze 的任务参数建议固定为：

```json
{
  "task_id": "20260826_153012_冷雾夹板",
  "product_name": "冷雾夹板",
  "analysis_type": "first_baseline",
  "period_start": "2026-08-01",
  "period_end": "2026-08-25",
  "user_message": "这是首次分析，没有历史基准。",
  "files": [
    {
      "name": "原始聊天记录.csv",
      "type": "csv",
      "url": "coze_uploaded_file_url_or_file_id"
    }
  ]
}
```

## 四、工作流节点

```text
1. 接收用户消息
   - 接收文字说明
   - 接收文件
   - 生成 task_id

2. 文件读取
   - 读取 csv/xlsx/log/txt
   - 提取聊天原文
   - 识别日期、买家、客服、消息内容

3. 任务判断
   - 首次分析
   - 有历史基准分析
   - 只补充分析

4. 基准读取
   - 如果有历史基准，读取上一期 Excel
   - 提取词条、定义、售前售后归属、去重口径

5. 需求分析
   - 调用 gpt5.6sol
   - 执行赤兔总规则
   - 拆分多需求
   - 判断售前/售后
   - 生成一级主题和二级词条

6. 去重统计
   - 同一买家 + 同一阶段 + 同一需求词条 + 当前周期，只计 1 次
   - 重复原话进入同人重复记录

7. P0/质量/安全二次复核
   - 漏电、流血、过敏、烫伤、冒烟、破损、无法开机、异常发热等必须复读上下文
   - 排除假设性提问、评论区转述、客服主动介绍

8. Excel 生成
   - 分析总览
   - 一级主题
   - 售前需求统计
   - 售后需求统计
   - 质量安全风险
   - 逐条需求明细
   - 同人重复记录
   - 待人工复核
   - 词条字典
   - 口径说明
   - 有效原始消息

9. 写入历史结果
   - 保存原始文件
   - 保存过程文件
   - 保存 Excel
   - 保存管理结论
   - 更新 analysis_index

10. 返回网页
   - 返回 3-6 条核心结论
   - 返回 Excel 文件入口
   - 返回 Markdown 结论入口
```

## 五、最终返回给网页的 JSON

```json
{
  "status": "completed",
  "task_id": "20260826_153012_冷雾夹板",
  "message": "分析已完成",
  "summary": [
    "售后使用方法咨询占比最高，建议优先优化说明书和自动回复。",
    "本期存在安全风险原话，需要人工复核。",
    "售前主要集中在适用人群、效果和质保。"
  ],
  "files": {
    "excel": "下载地址或文件路径",
    "markdown": "下载地址或文件路径"
  }
}
```

## 六、异常返回

```json
{
  "status": "failed",
  "task_id": "20260826_153012_冷雾夹板",
  "message": "聊天记录无法解析，请检查文件格式。",
  "need_user_action": true
}
```
