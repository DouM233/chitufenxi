# Coze 接入方式说明

赤兔工作台有三种接入方式。

## 方式一：Coze 低代码页面

适合把整个工具放在 Coze 平台内。

页面组件：

- 产品名输入框
- 分析类型选择器
- 周期开始/结束日期
- 基准文件输入或选择
- 文件上传组件
- 多行文本输入
- 开始分析按钮
- 分析进度展示
- 最终报告下载区域

按钮动作：

```text
收集页面参数 -> 调用赤兔分析工作流 -> 展示返回 JSON -> 展示文件入口
```

## 方式二：Coze Chat SDK

适合在外部网页嵌入 Coze 机器人。

优点：

- 接入快
- 聊天体验自然
- 可以复用 Coze Bot 能力

注意：

- 文件上传能力以 Coze 发布渠道和 SDK 当前能力为准。
- 生产环境不要把长期有效 token 写进前端。

## 方式三：Workflow API Proxy

适合最稳定的生产部署。

网页不直接调用 Coze，而是调用你的后端代理：

```text
网页 -> 你的后端 /api/chitu-analyze -> Coze Workflow API -> 返回结果
```

优点：

- token 不暴露
- 文件上传和历史归档更可控
- 后端可以直接维护《赤兔历史分析结果》

推荐生产方案：

```text
方式三
```

如果必须完全在 Coze 内部署，则优先使用方式一。
