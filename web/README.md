# 网页入口

`index.html` 是赤兔客服聊天分析的简洁聊天框版本。

当前页面只保留三件事：

- 发送文字说明
- 上传聊天记录或历史基准文件
- 生成并发送 Coze 分析任务

用户不需要在页面上选择“是否有历史基准”。网页会优先按上传文件组合判断：

- 做上期基准对照：同时上传上次分析基准和本次聊天记录。
- 不对照上期基准：只上传本次聊天记录文件。

文字说明仍然可以补充产品名、周期和特殊要求，例如：

```text
这是冷雾夹板 8月聊天记录，首次分析，没有历史基准。
```

或：

```text
这是新一期聊天记录，我已经上传了上期基准，请沿用上期词条做对比分析。
```

正式接入 Coze 时，发送按钮会把以下内容交给工作流：

```text
用户消息
上传文件
analysis_type
input_mode
baseline_files
chat_files
模型 gpt5.6sol
赤兔历史分析结果保存要求
```

当前本地服务生成新 Excel 时会复制 Codex 正式报告母版，并把本次聊天记录解析后的售前/售后统计、风险、逐条明细、重复记录和词条口径写入同一母版，确保 Sheet 顺序、列宽、行高、颜色、边框、合并区域等表格格式与正式 Codex 输出保持一致。

当前默认连接本地服务：

```text
http://127.0.0.1:8787/api/chitu-analyze
```

启动方式：

```text
node ../local-server.mjs
```

正式部署时，可以在 `config.js` 中切换为：

- `chat_sdk`
- `workflow_api_proxy`
