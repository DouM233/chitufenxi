# 词条命名与继承规则

词条应该满足：

1. 运营能看懂。
2. 能对应具体动作。
3. 不要太粗。
4. 不要无限细分。

不好：

```text
产品问题
```

好：

```text
无法开机/充电
不出雾/雾小
使用后皮肤不适
按摩力度异常
```

## 两层结构

保留两层结构：

一级主题：方便管理层看趋势。

二级词条：方便产品、运营、客服定位问题。

例如：

```text
一级主题：水雾系统
二级词条：加水方法、水箱拆装、冷雾触发、不出雾、雾量小、水箱漏水
```

## 有历史基准

有历史基准时：

```text
能用旧词条就不用新词条。
```

新增词条必须说明：

- 为什么旧词条无法覆盖。
- 新词条定义。
- 售前/售后归属。
- 代表性原话。

## 新品首次分析

新品首次分析时：

```text
禁止继承其他产品词条。
```

必须建立该产品自己的 V1 词条字典和 V1 基准。
