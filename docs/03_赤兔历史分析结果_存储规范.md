# 《赤兔历史分析结果》存储规范

`赤兔历史分析结果` 是整个系统最重要的归档目录。

它要保存三类东西：

1. 用户发来的原始聊天记录。
2. 分析过程中的中间文件。
3. 最终输出给用户的分析报告。

## 一、任务目录

每次用户点击“开始分析”，创建一个独立任务目录：

```text
赤兔历史分析结果/
└─ 03_最终报告/
   └─ 2026/
      └─ 08/
         └─ 20260826_153012_冷雾夹板/
```

任务目录中必须包含：

```text
用户文字说明.md
上传文件清单.json
口径检查.md
分析报告.xlsx
管理结论.md
result_manifest.json
```

## 二、result_manifest.json

每个任务最终必须生成一个 `result_manifest.json`：

```json
{
  "task_id": "20260826_153012_冷雾夹板",
  "product_name": "冷雾夹板",
  "analysis_type": "first_baseline",
  "period_start": "2026-08-01",
  "period_end": "2026-08-25",
  "model": "gpt5.6sol",
  "status": "completed",
  "input_files": [
    "原始聊天记录.csv"
  ],
  "output_files": {
    "excel": "冷雾夹板_20260826_客服聊天需求分析报告.xlsx",
    "markdown": "冷雾夹板_20260826_管理结论.md"
  },
  "created_at": "2026-08-26 15:30:12"
}
```

## 三、analysis_index

`00_索引/analysis_index.xlsx` 用来让网页快速读取历史分析列表。

字段建议：

```text
task_id
产品名
分析类型
周期开始
周期结束
模型
状态
Excel路径
管理结论路径
创建时间
备注
```

## 四、旧文件处理

当前已有的历史文件不要删除。

建议先移动或登记到：

```text
赤兔历史分析结果/99_旧文件归档/
```

如果暂时不移动，也可以先建 `analysis_index.xlsx`，把旧文件逐个登记进去。
