# 网页界面设计

网页第一版建议做成“左侧历史，右侧聊天”的工作台，而不是营销页。

## 一、核心页面

```text
┌────────────────────────────────────────────┐
│ 赤兔客服聊天分析工作台                      │
├───────────────┬────────────────────────────┤
│ 历史分析结果   │ 聊天区                      │
│ 产品筛选       │ - 用户发送文字               │
│ 时间筛选       │ - 用户上传文件               │
│ 报告列表       │ - Coze 返回分析进度           │
│               │ - Coze 返回最终结论           │
├───────────────┴────────────────────────────┤
│ 输入框：说明本次任务 / 上传聊天记录 / 开始分析 │
└────────────────────────────────────────────┘
```

## 二、用户可以做什么

- 输入产品名、分析周期、是否首次分析。
- 上传 `.csv`、`.xlsx`、`.log`、`.txt` 聊天记录。
- 发送补充说明，例如“这是首次分析，没有历史基准”。
- 查看分析进度。
- 下载最终 Excel。
- 查看 3-6 条管理结论。
- 打开历史报告。

## 三、聊天消息类型

建议至少支持：

```text
user_text        用户文字
user_file        用户上传文件
assistant_status 分析进度
assistant_result 最终结果
assistant_error  异常提醒
```

## 四、最终返回格式

Coze 返回给网页的最终消息建议固定为：

```json
{
  "status": "completed",
  "task_id": "20260826_153012_冷雾夹板",
  "product_name": "冷雾夹板",
  "period": "2026-08-01 至 2026-08-25",
  "summary": [
    "售后使用方法咨询占比最高，说明用户收到货后的学习成本偏高。",
    "安全风险中存在少量烫伤相关原话，需要单独复核。",
    "售前主要集中在适用发质、冷雾效果和质保政策。"
  ],
  "excel_file": "赤兔历史分析结果/03_最终报告/2026/08/20260826_153012_冷雾夹板/冷雾夹板_20260826_客服聊天需求分析报告.xlsx",
  "markdown_file": "赤兔历史分析结果/03_最终报告/2026/08/20260826_153012_冷雾夹板/冷雾夹板_20260826_管理结论.md"
}
```

## 五、第一版先不做的功能

- 多人权限管理。
- 复杂 BI 看板。
- 自动识别全部产品档案。
- 跨店铺长期趋势大屏。

第一版先把“上传、分析、归档、下载、复查”跑通。
