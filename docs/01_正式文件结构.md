# 赤兔聊天分析工作台正式文件结构

建议最终采用双层结构：

1. `赤兔聊天分析工作台/`：保存网页、Coze 配置、规则模板、产品档案。
2. `赤兔历史分析结果/`：保存用户发送的聊天记录、原始文件、过程文件、最终报告。

## 一、工作台项目结构

```text
赤兔聊天分析工作台/
│
├─ 00_README.md
│
├─ docs/
│  ├─ 01_正式文件结构.md
│  ├─ 02_网页界面设计.md
│  └─ 03_赤兔历史分析结果_存储规范.md
│
├─ coze/
│  ├─ 01_Coze工作流设计.md
│  ├─ 02_Coze变量清单.md
│  ├─ 03_Coze发布检查清单.md
│  └─ prompts/
│     ├─ system_赤兔总规则.md
│     ├─ prompt_首次分析.md
│     └─ prompt_有基准分析.md
│
├─ web/
│  ├─ index.html
│  ├─ config.js
│  ├─ config.example.js
│  ├─ assets/
│  └─ README.md
│
├─ templates/
│  ├─ 产品档案模板.yaml
│  ├─ 分析任务模板.yaml
│  └─ Excel报告字段模板.md
│
├─ products/
│  ├─ 冷雾夹板.yaml
│  ├─ 筋膜枪.yaml
```

## 三、命名规则

推荐任务 ID：

```text
YYYYMMDD_HHMMSS_产品名
```

示例：

```text
20260826_153012_冷雾夹板
```

最终报告命名：

```text
产品名_YYYYMMDD_客服聊天需求分析报告.xlsx
产品名_YYYYMMDD_管理结论.md
```
