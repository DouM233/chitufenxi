# Excel 输出模板规范

本规范来自两个历史参考报告：

- `2449小气泡_20260812-0818_客服聊天需求分析报告.xlsx`
- `A17按摩枕_按运营原口径复算_20260726-0824_客服聊天分析报告.xlsx`

默认输出采用 2449 的通用客服需求分析结构；如果用户明确要求“按运营原口径复算”，再扩展 A17 类型的运营口径 Sheet。

## 一、默认 Sheet

```text
分析总览
售前需求统计
售后需求统计
售前基准对比
售后基准对比
新增词条
P0风险明细
安全质量风险
逐条需求明细
同人重复记录
待人工复核
词条与口径
上期基准
原始数据
```

## 二、分析总览

第一屏必须让管理者看懂。

必须包含：

```text
数据规模
消息规模
需求结果
重复治理
安全质量
交付文件
TOP售前
TOP售后
风险概览
核心业务结论
```

核心结论必须是大白话，按照“发现 -> 判断 -> 动作”写。

## 三、售前/售后需求统计字段

```text
排名
需求词条
同人去重人数
占比
日均人数
原始命中
重复次数
优先级
严格定义
涉及买家示例
代表原话
建议动作
```

## 四、基准对比字段

```text
需求词条
本期人数
本期占比
本期日均
基准人数
基准占比
基准日均
人数变化
占比变化
变化判断
建议动作
备注
```

如果两个周期天数不同，禁止只比较总人数，必须比较占比和日均。

## 五、风险字段

P0 和安全质量风险必须单独出表。

```text
风险ID / ID
风险词条 / 需求词条
买家
日期
时间
代表原话
全部证据
源行
优先级 / 原始命中
建议动作
```

风险必须二次校准，排除假设性提问、评论区转述、客服主动介绍、正常使用咨询。

## 六、证据字段

逐条需求明细必须至少保留：

```text
明细ID
阶段
需求词条
买家
日期
时间
代表原话
同需求全部原话
源行
原始命中
一级主题
口径层
```

同人重复记录必须保留重复原话、保留原话和剔除原因。

## 七、运营原口径复算扩展

如果用户要求按运营原口径复算，额外增加：

```text
运营原口径
运营口径复算
当前售前明细
售后问题扩展
售后正常咨询
```

这类报告不直接把评价/问答样本数量和客服聊天数量做环比，只做结构参考。

## 八、三 SKU 首次基准报告

如果用户一次上传同一品类下三款 SKU，且说明没有历史基准，应优先采用“三款产品首次 V1 基准”结构。

参考标准：

```text
丹橘卷发棒三款产品_20260726-0824_首次客服聊天需求基准分析报告.xlsx
```

模板母版：

```text
templates/excel/三SKU首次基准_卷发棒标准模板.xlsx
```

生成原则：

```text
先复制模板母版，再填数据。
```

不要用代码重新画一个“相似模板”。必须继承母版中的：

```text
Sheet 顺序
Sheet 名称
标题行合并区域
说明区位置
红色标题色
浅色说明底色
表头底色
字体
边框
列宽
行高
冻结窗格
数字格式
图表位置
图表颜色
```

后续只允许替换数据值和必要的文本内容，不允许重建整体视觉结构。

必须包含：

```text
分析总览
三款产品对比
856售前V1
856售后V1
366售前V1
366售后V1
五合一售前V1
五合一售后V1
质量安全风险
跨产品共性
每日趋势
逐条需求明细
同人重复记录
待人工复核
V1词条字典
口径说明
有效买家消息
```

关键要求：

- 不输出通用的 `售前需求统计/售后需求统计` 作为主表，而是按 SKU 分别输出 `售前V1/售后V1`。
- 必须有 `三款产品对比`，用于横向判断三款 SKU 的结构差异。
- 必须有 `跨产品共性`，沉淀共性问题和分产品优先动作。
- 必须有 `每日趋势`，按日期、产品、售前、售后、风险统计。
- 质量安全风险只保留用户本人实际发生的较强异常。
- 购买前“会不会伤发/会不会烫/会不会漏电”等只算售前安全顾虑，不进入真实风险。
- “使用方法/教程/换头/怎么拆”默认归售后，因为代表实际客服承接压力。
- 同一商品 + 买家 + 阶段 + 需求词条 + 当前周期只计 1 次。

三 SKU 报告不应把不同产品合并成一个粗粒度词条表后结束；合并表只能作为总览，真正的 V1 基准必须落到每款产品自己的售前/售后 Sheet。
